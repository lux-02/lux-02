# Portfolio Asset Checklist (Darkwinterlab)

이 문서의 항목을 준비해주시면, 최종 디자인 품질을 빠르게 끌어올릴 수 있습니다.

## 1) Brand Assets

- 로고 원본 (SVG 권장, PNG 보조)
- 심볼/워드마크 분리본 (가능하면)
- 브랜드 컬러 가이드
  - primary
  - secondary
  - accent
- 파비콘 세트 (`favicon.ico`, `apple-touch-icon`, `site.webmanifest`)

## 2) Profile Assets

- 프로필 사진 (최소 1200x1200, 정사각형)
- 짧은 소개 문구(한/영)
- 한 줄 포지셔닝 문구(한/영)

## 3) Project Assets (프로젝트별)

각 프로젝트마다 아래를 준비해주세요.

- 대표 썸네일 1장 (1200x630 권장)
- 상세 스크린샷 3~6장
- 가능하면 10~20초 데모 GIF 또는 짧은 영상 링크
- 프로젝트 요약 (문제/해결/성과 각 2~4문장)
- 정량 지표
  - 예: 사용자 수, 처리량, 정확도, 절감 시간, 수상 성과
- 링크 세트
  - GitHub Repo
  - Live Service
  - News / Press
  - Demo video (있다면)

## 4) Awards / Credentials

- 수상명, 주최, 날짜
- 증빙 이미지 또는 공식 링크
- 핵심 문장 1개(왜 중요한지)

## 5) Contact / Lead Generation

- 문의 받을 공식 이메일
- LinkedIn URL
- GitHub URL
- 문의 폼 수신 엔드포인트
  - 권장: Formspree/Web3Forms/자체 API
  - 현재 사이트는 `NEXT_PUBLIC_CONTACT_FORM_ENDPOINT` 환경 변수 사용

## 6) SEO / Sharing

- 사이트 기본 제목/설명(한/영)
- OG 이미지 (최소 1200x630)
- 주요 키워드 10~20개
- 도메인 연결 정보 (`darkwinterlab.com` DNS/배포 플랫폼)

## 7) Optional (추천)

- 보안 연구/블로그 글 링크 모음
- 발표 영상/인터뷰/행사 사진
- 오픈소스 기여 링크
